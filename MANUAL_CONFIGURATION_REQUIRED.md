# Manual Configuration Required

This document lists the configuration items that you must personally provide. These are external credentials that belong to your accounts and cannot be safely generated by the system.

## Required Configuration (Set Before Starting Backend)

### 1. Database Connection
**Where**: `server/.env` → `DATABASE_URL`
**What**: PostgreSQL database connection string
**Why**: Required for all database operations
**Required**: NOW - Backend will not start without this

### 2. JWT Secret
**Where**: `server/.env` → `JWT_SECRET`
**What**: A strong random secret string (minimum 32 characters recommended)
**Why**: Used to sign and verify authentication tokens
**Required**: NOW - Backend will not start without this

### 3. Supabase Credentials
**Where**: `server/.env` → `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY`
**What**: Supabase project URL and service role key
**Why**: Required for password reset email delivery via Supabase Auth
**Required**: NOW - Password reset will not work without this

### 4. Firebase Admin Credentials
**Where**: Either provide `server/firebase-service-account.json` file OR set:
- `server/.env` → `FIREBASE_PROJECT_ID`
- `server/.env` → `FIREBASE_PRIVATE_KEY`
- `server/.env` → `FIREBASE_CLIENT_EMAIL`

**What**: Firebase Admin SDK credentials for FCM push notifications
**Why**: Required for sending push notifications to mobile devices
**Required**: NOW - Push notifications will not work without this

### 5. Cloudinary Credentials
**Where**: `server/.env` → `CLOUDINARY_CLOUD_NAME`, `CLOUDINARY_API_KEY`, `CLOUDINARY_API_SECRET`
**What**: Cloudinary account credentials for image uploads
**Why**: Required for driver document uploads and profile pictures
**Required**: NOW - Image uploads will not work without this

### 6. Gmail SMTP Credentials
**Where**: `server/.env` → `GMAIL_USER` and `GMAIL_APP_PASSWORD`
**What**: Gmail email address and app-specific password
**Why**: Required for OTP verification and password reset emails
**Required**: NOW - Email features will not work without this

## Optional Configuration (For Production)

### 7. Gmail OAuth2 Credentials
**Where**: `server/.env` → `GMAIL_CLIENT_ID`, `GMAIL_CLIENT_SECRET`, `GMAIL_REFRESH_TOKEN`
**What**: OAuth2 credentials for Gmail API (bypasses port blocks)
**Why**: Production email delivery via HTTPS instead of SMTP
**Required**: LATER - SMTP will be used as fallback if not set

### 8. CORS Allowed Origins
**Where**: `server/.env` → `CORS_ALLOWED_ORIGINS`
**What**: Comma-separated list of allowed frontend origins
**Why**: Security - restricts which domains can access your API
**Required**: NOW - Defaults to localhost and production URL if not set

### 9. Admin Portal API URL
**Where**: `admin-portal/.env` → `VITE_API_BASE_URL`
**What**: Backend API base URL for admin portal
**Why**: Connects admin portal to backend
**Required**: NOW - Admin portal will not work without this

## Configuration Steps

1. Copy `server/.env.example` to `server/.env`
2. Copy `admin-portal/.env.example` to `admin-portal/.env`
3. Fill in all required values in both files
4. Do NOT commit `.env` files to Git (they are in .gitignore)
5. For production deployment, set these as environment variables in your hosting platform (Render, etc.)

## Notes

- The Google Maps API key is currently hardcoded in the mobile app (`app.json` and `src/services/googlePlaces.ts`). This should be moved to environment variables in a future phase, but for now the existing key is functional.
- The Firebase project ID (`lahore-pink-rides`) is hardcoded in multiple places. This is the actual project ID and should not need to change.
